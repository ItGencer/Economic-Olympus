9. Логіка клітинок
a) Сделка
Відкривається вертикальна картка:
Дохід: random 1000–10000
Важність: random 2–12
Кнопки: Погодитися / Відмовитись
Якщо погодився:
кидок 2 кубиків
якщо імідж ≥ 0 → додається до суми
якщо імідж < 0 → віднімається
якщо результат ≥ важності → дохід додається до балансу
інакше → дохід віднімається з балансу

b) Казино
Гравець вводить суму Обирає: парне / непарне
Кидок 2 кубиків:
збіг → сума * 2 додається до балансу, не збіг → сума віднімається

c) Імідж
Random імідж: 2–5
Ціна: random 100–3000
Погодився → списується баланс, додається імідж

d) Random
Випадкова подія
Може бути + або –
Кнопка “Далі”
Сума додається або віднімається

e) Негативна репутація –1 до іміджу

f) Зарплата / премія. Якщо імідж > 0:
імідж * 500 → додається до балансу

g) Податкова
–20% від поточного балансу

h) Реклама
Ціна: 100–1000
Імідж: 1–10
Погодився → зняти гроші, додати імідж

i) Позитивна репутація +1 до іміджу

10. Клієнт
Random “відношення” 1–6
Якщо погодився:
гравець кидає кубик → додається до іміджу банк кидає кубик → додається до відношення різниця → % гравець обирає кількість товарного запасу баланс збільшується відповідно до %

12. Компанії (6 штук)
У кожній компанії 100 акцій.
Гравці можуть купувати акції.
Акції впливають на: товарний запас контроль компанії Неможливо перевищити 100%

13. Директор та Генеральний директор
Якщо у гравця ≥51% акцій → може стати директором
Кожен директор має: статус коефіцієнт голосування
Для Генерального директора:
потрібно набрати ≥51% голосів кидок кубиків по кожному директору. Якщо успіх → гра завершується

14. Борги
Якщо баланс < 0 на зовнішньому колі:
гравець повертається на внутрішнє коло (Start) всі активи зберігаються поки не погасить борг — не може вийти

15. Початок гри / Налаштування
Після “Почати гру” відкривається блок Налаштування
Вибір:
2–6 учасників скільки гравців / скільки ботів

Боти (комп'ютер): діють за тими ж правилами самі приймають рішення
Після вибору → активна кнопка “Почати гру”
